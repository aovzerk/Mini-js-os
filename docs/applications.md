# Приложения MyOS

Руководства разделены по среде выполнения:

- [c-applications.md](c-applications.md) — создание консольных и графических
  программ на C, точка входа, ABI и добавление `.BIN` в образ;
- [js-applications.md](js-applications.md) — синтаксис JS-runtime, модуль
  `myos`, окна, массив процессов и создание `.JS`-приложений.

Общие правила сборки и диагностики находятся в
[development.md](development.md), системные вызовы — в
[syscalls.md](syscalls.md).
