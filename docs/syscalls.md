# Системные вызовы

## ABI

Пользовательские обёртки находятся в `pm32/include/myos/api.h`. Номер вызова передаётся
в EAX, первые два аргумента — в EBX и ESI. ECX содержит пользовательский ESP,
EDX — адрес возврата. Затем выполняется `SYSENTER`.

`pm32/kernel/syscalls.asm` сохраняет запрос в `KernelRequest`, переключает
сегменты на flat kernel data и вызывает `kernel_dispatch` в C. Возврат в CPL3
выполняется через `SYSEXIT`.

Последовательность байтов в pragma:

```text
call +0; pop edx; add edx, 6; sysenter
```

нужна для получения адреса инструкции после `SYSENTER`. Её нельзя сокращать
без одновременного изменения ASM-моста.

## Таблица

| № | API | Назначение |
|---:|---|---|
| 0 | внутренний | очистка начальной консоли |
| 1 | `sys_write` | вывод в консоль или терминальный канал |
| 2 | `sys_exit` | завершение дочернего процесса |
| 3 | `sys_exec` | замена текущей программы |
| 4 | `sys_read_key` | чтение клавиши из очереди |
| 5 | `sys_read_file` | чтение файла FAT 8.3 |
| 6 | `sys_spawn` | асинхронный запуск console-программы |
| 7 | `sys_yield` | передача CPU планировщику |
| 8 | `sys_send_key` | помещение клавиши в очередь процесса |
| 9 | `sys_terminal_read` | чтение вывода терминального канала |
| 10 | `sys_get_pid` | PID текущего процесса |
| 11 | `sys_kill` | завершение дочернего процесса из GUI |
| 12 | внутренний | создание адресного пространства PID 0 |
| 13 | внутренний | загрузка начального `SHELL.BIN` |
| 14 | `sys_run` | запуск console-программы с ожиданием |
| 15 | `sys_write_file` | создание или перезапись файла |
| 16 | `sys_get_app_type` | тип текущего приложения |
| 17 | `sys_spawn_gui` | запуск только GUI-программы |
| 18 | `sys_list_files` | список файлов корневого каталога |
| 19 | `sys_poweroff` | выключение через ACPI/QEMU |
| 20 | `sys_gui_create_window` | запрос GUI-окна текущим GUI-процессом |
| 21 | `sys_gui_next_window` | получение GUI-сервером следующего запроса окна |
| 22 | `sys_list_processes` | массив структур `ProcessInfo` активных процессов |
| 23 | `sys_gui_set_title` | установка заголовка окна текущего GUI-процесса |
| 24 | `sys_gui_get_title` | получение GUI-сервером заголовка процесса |
| 25 | `sys_malloc` | выделение обнулённого блока из heap текущего процесса |
| 26 | `sys_free` | обнуление и освобождение блока текущего процесса |
| 27 | `sys_millis` | монотонное время PIT в миллисекундах |

Вызов 22 записывает в переданный буфер до указанного числа структур
`ProcessInfo` и возвращает фактическое количество записей. Структура содержит
PID, имя, флаг активности, тип приложения, parent PID и terminal PID. Ядро не
форматирует текст или заголовок таблицы.

При добавлении вызова необходимо синхронно изменить:

1. объявления и pragma в `api.h`;
2. ветку номера в `kernel_dispatch`;
3. эту таблицу.
